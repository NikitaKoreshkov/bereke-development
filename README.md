# Bereke Development — сайт застройщика

Одностраничный лендинг бизнес-центра **BEREKE** (Алматы).

## Стек

- Next.js 16 + TypeScript + Tailwind CSS

## Запуск

```bash
npm install
npm run dev
```

Открыть [http://localhost:3000](http://localhost:3000)

## Контент

Тексты и структура — в `lib/site-data.ts`.  
Изображения — в `public/images/` (заменить на финальные рендеры от клиента).

## Сборка

```bash
npm run build
npm start
```
